# Climate Intelligence Dashboard

Static HTML, CSS, and JavaScript dashboard for correlating weather forecasts with environmental risk indicators.

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files directly to the repository root:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `.nojekyll`
3. Go to repository `Settings > Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save and wait for GitHub to publish the site.

The mobile URL should look like:

`https://your-username.github.io/your-repository-name/`
